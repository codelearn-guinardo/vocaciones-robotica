Introducción

La robótica es la rama de la tecnología que se encarga de diseñar, construir y programar robots, es decir, máquinas capaces de realizar tareas físicas de forma automática o semiautomáticas.

Es el resultado de combinar la electrónica, mecánica y programación.

Una forma sencilla de entenderlo: Cuando vimos que en programación un programa recibía datos, realizaba un proceso y generaba un resultado o efecto.
En este caso funciona de una forma análoga: El robot recibe una señal del entorno, realiza un procesamiento y desarrolla una acción. señal → procesamiento → acción.

Señal

Es la información que percibe del entorno el robot a través de un sensor. Un sensor es un dispositivo mediante el cual se puede percibir una señal del entorno y traducirla a una señal eléctrica.

Metáfora: son los sentidos del sistema. Igual que una persona puede ver cuando una puerta se abre, un sensor puede detectar eso mismo.

Procesamiento

Al percibirse una señal del entorno, el procesamiento es el conjunto de operaciones que realiza internamente el robot con dicha señal. El procesamiento que se realice viene dado por cómo esté programado el robot.

Metáfora: El sistema reacciona a cuando recibe la señal y procesa dicha información. Por ejemplo, una persona al recibir una llamada telefónica primero mira el número o contacto que le está llamando, y en base a ello toma una decisión de qué hacer.

Acción

El procesador del robot envía una señal eléctrica al elemento actuador correspondiente, accionándolo. Un actuador es cualquier elemento conectado a la placa base del robot que puede ser accionado por una señal eléctrica para realizar un trabajo físico. Dicho trabajo puede ir desde emitir luz o sonido hasta mover una pieza articulada o enviar señales a otro dispositivo.

Metáfora: La acción de descolgar el teléfono y abrir la agenda después de procesar la recepción de la llamada.

Conceptos a recordar

  • Algoritmo: conjunto ordenado, finito y no ambiguo de pasos para resolver una tarea.
  • Programa: instrucciones que puede ejecutar una máquina. Es el resultado de codificar un algoritmo mediante un lenguaje de programación.
  • Sensor: componente que detecta una señal del entorno y la traduce a una señal eléctrica.
  • Actuador: componente que realiza una acción al recibir una señal eléctrica.
  • Variable: espacio en memoria donde guardamos un dato que puede usarse o cambiar en otro momento de la ejecución de un programa.
  • Derivación condicional: Permite ejecutar una o varias instrucciones en base al cumplimiento de una condición o valor lógico.
  • Bucle: Permite ejecutar una o varias acciones varias veces.
  • Prototipo: primera versión de la implementación de una idea que utilizamos para probarla.
  • Depuración: Proceso de monitorización de la ejecución de un programa con el objetivo de detectar y corregir errores o bugs. Se puede ver la ejecución paso a paso y el valor de las variables en todo momento, con tal de detectar inconsistencias.
Ejemplo cotidiano de algoritmo: preparar un vaso de agua puede describirse paso a paso: coger el vaso → abrir el grifo → llenar el vaso → cerrar el grifo. Un programa hace algo parecido, pero con instrucciones que entiende la máquina.

Makey Makey

Makey Makey es una placa electrónica basada en Arduino que funciona como un emulador de teclado y ratón, permitiendo convertir cualquier objeto conductor en un controlador interactivo para el ordenador. Es una forma sencilla de experimentar con circuitos, entradas e interacción.

¿Cómo funciona?

Cuando tocamos un objeto conectado a Makey Makey y completamos el circuito, la placa envía una señal al ordenador.

Metáfora: imagina un timbre. Al pulsarlo se cierra un circuito y el timbre suena. Makey Makey utiliza una idea parecida para detectar una interacción.

Materiales

Podemos utilizar papel de aluminio, plastilina conductora, monedas y otros materiales que permitan conducir electricidad.

Ejemplo: una banana puede convertirse en un botón para controlar una aplicación si forma parte del circuito.

Para las actividades

  • Haremos grupos de 2 para compartir los makey makey.
  • Leed con atención las instrucciones de las actividades y realizar el análisis en conjunto.
  • Recuerda que para que funcione tienes que cerrar el circuito.
  • Si una actividad resulta muy complicada, pasa a la siguiente.
  • No es necesario que resuelvas todas las actividades propuestas.

Actividad Mk1: piano

  1. Crea un nuevo proyecto de Scratch.
  2. Añade las extensiones "Música" y "Makey makey".
  3. Crea un teclado de 6 teclas utilizando cartón y paple de aluminio, conectándolo a la placa de forma adecuada usando los cables con pinza.
  4. Al pulsar cada una de las teclas debe producirse un sonido distinto.
  5. Opcional: Añade un control adicional para cambiar de sonido de instrumento.

Actividad Mk2: Juego de naves

  1. Crea un nuevo proyecto de Scratch.
  2. Añade la extensión "Makey makey".
  3. Crea un mando de 3 botones (2 flechas + botón de acción) utilizando cartón y papel de aluminio, conectándolo a la placa de forma adecuada usando los cables con pinza.
  4. Crea un juego en el que una nave espacial se pueda mover lateralmente con las flechas y pueda disparar con el botón de acción. Solamente se permite un disparo a la vez y por segundo.
  5. Opcional: Haz que cada X segundos aparezca un alien. Los aliens deben desaparecer después de recibir 3 disparos.

micro:bit

micro:bit es una pequeña placa programable que permite trabajar con botones, sensores, LEDs y otros componentes.

Entradas

Los botones y sensores proporcionan información al programa.

Metáfora: son como los sentidos de una máquina: permiten saber qué está pasando.

Salidas

La matriz de LEDs y otros componentes permiten mostrar o producir una respuesta.

Metáfora: son como las manos o la voz de la máquina: sirven para expresar una respuesta.

Programación

Podemos comenzar con programación visual por bloques para trabajar eventos, variables, condiciones y bucles.

Algoritmos antes que código

Objetivo: mostrar una cara cuando se pulse el botón A.

  1. Esperar a que se pulse A.
  2. Mostrar una cara feliz.
  3. Esperar un segundo.
  4. Borrar la pantalla.

Este algoritmo es como una receta. Primero definimos los pasos y después los convertimos en instrucciones que micro:bit pueda ejecutar.

Actividad Bt1: Contador

Crea un programa que maneja un contador.

  • EL valor del contador comienza en 0.
  • Al pulsar A se incrementa el valor del contador en 1.
  • Al pulsar B se reduce el valor del contador en 1.
  • Al pulsar A+B se reinicia el valor del contador.
  • En todo momento se debe mostrar el valor actual del contador por pantalla.
  • El valor del contador se encontrará en todo momento entre 0 y 9.

Actividad Bt2: Dado

Crea un programa que permita simular tiradas de dado de 6 caras.

  • Al agitar la placa microbit, realiza la tirada, obtiene un número aleatorio y muestra por pantalla un dibujo distinto según el resultado.
  • En el caso de sacar un 6, se reproduce un sonido de celebración.
  • AL transcurrir 5 segundos después de la tirada, se borra la pantalla y se reproduce un sonido muy breve como aviso.
  • Solamente se puede realizar una tirada mientras la pantalla esté limpia.

Actividad Bt3: Termómetro

Crea un programa que permita mostrar la temperatura actual.

  • Al colocar la placa en posición vertical, la placa realiza una lectura de temperatura y la muestra por pantalla.
  • En el caso de sacar un 6, se reproduce un sonido de celebración.
  • AL transcurrir 5 segundos después de la tirada, se borra la pantalla y se reproduce un sonido muy breve como aviso.
  • Solamente se puede realizar una tirada mientras la pantalla esté limpia.
Ejemplo de condición

“Si la temperatura es mayor que 25 °C, mostrar un símbolo de calor; si no, mostrar un símbolo diferente”.

Es como decidir qué ropa ponerse: si hace frío, abrigo; si hace calor, ropa ligera.

Ejemplo de bucle

“Encender el LED → esperar → apagar el LED → esperar” y repetir.

Es como una canción que vuelve a empezar cuando llega al final.

Arduino

Arduino permite crear sistemas electrónicos conectando componentes a una placa y programando su comportamiento.

Componentes

🧩

Placa Arduino

Es el cerebro del proyecto: recibe señales, procesa datos y controla dispositivos conectados.

🔌

Protoboard

Permite montar y probar circuitos sin soldar, conectando componentes de forma rápida y reversible.

💡

LED

Emite luz cuando recibe corriente y se usa para mostrar estados, alertas o señales visuales.

⚡

Resistencia

Limita la corriente que pasa por un circuito y ayuda a proteger componentes sensibles.

🕹️

Botón

Actúa como entrada: cuando se pulsa, cambia la dirección del circuito, permitiendo desencadenar acciones.

📡

Sensor

Detecta condiciones del entorno como luz, temperatura, movimiento o proximidad.

⚙️

Motor

Convierte energía eléctrica en movimiento para empujar, girar o hacer funcionar mecanismos.

Ejemplo de programa Arduino en C++: LED intermitente

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);

  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
}
Qué ocurre: Arduino enciende el LED, espera medio segundo, lo apaga, espera otro medio segundo y repite el proceso. Es como encender y apagar una lámpara siguiendo un reloj.

Componentes y seguridad

  • Comprueba siempre dónde debe conectarse cada componente.
  • Respeta la polaridad de componentes que la tengan.
  • Utiliza resistencias adecuadas para proteger los LEDs.
  • Evita realizar conexiones al azar.
  • Antes de modificar un circuito, desconecta la alimentación cuando corresponda.

Actividad: sistema de aviso

Construye un sistema que detecte una situación mediante un botón o sensor y produzca una respuesta mediante un LED, un sonido u otro actuador.

  1. Define qué quieres detectar.
  2. Elige la entrada.
  3. Decide qué debe ocurrir.
  4. Elige la salida.
  5. Construye el circuito.
  6. Programa el comportamiento.
  7. Prueba y corrige los errores.
Ejemplo cotidiano: una luz automática de un pasillo puede detectar movimiento. El sensor sería la entrada, Arduino tomaría la decisión y la lámpara sería la salida.
