Introducción

La robótica combina mecánica, electrónica y programación para crear sistemas capaces de recibir información, procesarla y realizar acciones.

Una forma sencilla de entenderlo: piensa en una persona que recibe un mensaje, decide qué hacer y actúa. Un sistema robótico funciona de forma parecida: entrada → procesamiento → salida.

Entrada

Es la información que recibe el sistema. Puede proceder de un botón, un sensor de luz, un sensor de distancia, un micrófono o un detector de movimiento.

Metáfora: son los sentidos del sistema. Igual que una persona ve que una puerta está abierta, un sensor puede detectar esa situación.

Procesamiento

Es la parte que interpreta la información y decide qué hacer. Una placa electrónica ejecuta el programa que hemos creado.

Metáfora: es como el cerebro siguiendo unas instrucciones: “si ocurre esto, haz aquello”.

Salida

Es la acción que realiza el sistema: encender un LED, emitir un sonido, mover un motor o mostrar un mensaje.

Metáfora: es la respuesta del sistema, como cuando una persona escucha el timbre y abre la puerta.

Conceptos básicos

  • Algoritmo: conjunto ordenado de pasos para resolver una tarea.
  • Programa: instrucciones que puede ejecutar una máquina.
  • Sensor: componente que detecta algo del entorno.
  • Actuador: componente que realiza una acción.
  • Variable: espacio donde guardamos un dato que puede cambiar.
  • Condición: permite decidir entre diferentes acciones.
  • Bucle: permite repetir instrucciones.
  • Prototipo: primera versión de una idea que utilizamos para probarla.
  • Depuración: localizar y corregir errores.
Ejemplo cotidiano de algoritmo: preparar un vaso de agua puede describirse paso a paso: coger el vaso → abrir el grifo → llenar el vaso → cerrar el grifo. Un programa hace algo parecido, pero con instrucciones que entiende la máquina.

Makey Makey

Makey Makey permite utilizar objetos conductores como controles de un ordenador. Es una forma sencilla de experimentar con circuitos, entradas e interacción.

¿Cómo funciona?

Cuando tocamos un objeto conectado a Makey Makey y completamos el circuito, la placa envía una señal al ordenador.

Metáfora: imagina un timbre. Al pulsarlo se cierra un circuito y el timbre suena. Makey Makey utiliza una idea parecida para detectar una interacción.

Materiales

Podemos utilizar papel de aluminio, plastilina conductora, monedas y otros materiales que permitan conducir electricidad.

Ejemplo: una banana puede convertirse en un botón para controlar una aplicación si forma parte del circuito.

Qué aprendemos

  • Qué es una entrada.
  • Qué significa cerrar un circuito.
  • Cómo una acción física puede producir una respuesta digital.
  • Cómo diseñar controles sencillos.

Actividad: piano de objetos

  1. Conecta Makey Makey al ordenador.
  2. Prepara varios objetos conductores.
  3. Asigna una tecla diferente a cada objeto.
  4. Haz que cada tecla produzca una nota distinta.
  5. Prueba diferentes objetos y comprueba cuáles funcionan mejor.
Para pensar: si una puerta automática detecta que alguien se acerca y después abre la puerta, ¿cuál sería la entrada, cuál el procesamiento y cuál la salida?

micro:bit

micro:bit es una pequeña placa programable que permite trabajar con botones, sensores, LEDs y otros componentes.

Entradas

Los botones y sensores proporcionan información al programa.

Metáfora: son como los sentidos de una máquina: permiten saber qué está pasando.

Salidas

La matriz de LEDs y otros componentes permiten mostrar o producir una respuesta.

Metáfora: son como las manos o la voz de la máquina: sirven para expresar una respuesta.

Programación

Podemos comenzar con programación visual por bloques para trabajar eventos, variables, condiciones y bucles.

Algoritmos antes que código

Objetivo: mostrar una cara cuando se pulse el botón A.

  1. Esperar a que se pulse A.
  2. Mostrar una cara feliz.
  3. Esperar un segundo.
  4. Borrar la pantalla.

Este algoritmo es como una receta. Primero definimos los pasos y después los convertimos en instrucciones que micro:bit pueda ejecutar.

Actividad: contador

Crea un programa que aumente un número cada vez que se pulse el botón A.

Conceptos

  • Evento.
  • Variable.
  • Incremento.
  • Mostrar información.

Para ampliar

Utiliza el botón B para reducir el número y A+B para volver a cero.

Ejemplo de condición

“Si la temperatura es mayor que 25 °C, mostrar un símbolo de calor; si no, mostrar un símbolo diferente”.

Es como decidir qué ropa ponerse: si hace frío, abrigo; si hace calor, ropa ligera.

Ejemplo de bucle

“Encender el LED → esperar → apagar el LED → esperar” y repetir.

Es como una canción que vuelve a empezar cuando llega al final.

Arduino

Arduino permite crear sistemas electrónicos conectando componentes a una placa y programando su comportamiento.

Componentes

  • Placa Arduino.
  • Protoboard.
  • LEDs.
  • Resistencias.
  • Botones.
  • Sensores.
  • Motores y otros actuadores.

Protoboard

Permite montar circuitos sin soldar, facilitando las pruebas y los cambios.

Metáfora: es como una mesa de trabajo con piezas que podemos conectar, separar y reorganizar mientras construimos.

Entradas y salidas

Arduino puede leer información de sensores y controlar LEDs, motores, zumbadores y otros dispositivos.

Metáfora: el sensor avisa de lo que ocurre, Arduino toma la decisión y el actuador ejecuta la respuesta.

Primer programa: LED intermitente

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);

  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
}
Qué ocurre: Arduino enciende el LED, espera medio segundo, lo apaga, espera otro medio segundo y repite el proceso. Es como encender y apagar una lámpara siguiendo un reloj.

Componentes y seguridad

  • Comprueba siempre dónde debe conectarse cada componente.
  • Respeta la polaridad de componentes que la tengan.
  • Utiliza resistencias adecuadas para proteger los LEDs.
  • Evita realizar conexiones al azar.
  • Antes de modificar un circuito, desconecta la alimentación cuando corresponda.

Actividad: sistema de aviso

Construye un sistema que detecte una situación mediante un botón o sensor y produzca una respuesta mediante un LED, un sonido u otro actuador.

  1. Define qué quieres detectar.
  2. Elige la entrada.
  3. Decide qué debe ocurrir.
  4. Elige la salida.
  5. Construye el circuito.
  6. Programa el comportamiento.
  7. Prueba y corrige los errores.
Ejemplo cotidiano: una luz automática de un pasillo puede detectar movimiento. El sensor sería la entrada, Arduino tomaría la decisión y la lámpara sería la salida.
